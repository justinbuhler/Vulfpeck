# Domain docs

Single-context layout: optional root `CONTEXT.md` and `docs/adr/`.

## Before exploring

Read root `AGENTS.md`, and the `AGENTS.md` of every folder you touch.
Read `MEMORY.md` when it exists and follow relevant linked decisions.
If present, also read `CONTEXT.md` and relevant ADRs in `docs/adr/`.

Missing optional context files do not require scaffolding or block exploration.

## Decisions

Keep durable architectural decisions in `MEMORY.md` (What decided / Why / What rejected).
Keep dated failures, measurements and limitations in `ENGINEERING_LOG.md`.
Surface conflicts with recorded decisions, ADRs, or governing policy.
